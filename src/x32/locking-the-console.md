# {{ $frontmatter.title }}

You would want to lock the console if you are going to step away from it and you do not want anyone else messing with it.

> [!NOTE]
> Locking the console does not stop audio from passing through the console so lock the console if you need to walk away after soundcheck or after doors open.

## The Simple Way

### Locking

1. Press and hold the `HOME` button for 3-4 seconds. The screen should change to a blank page and all buttons and faders will no longer respond to changes.

### Unlocking

1. Press and hold the `HOME` button for 3-4 seconds. The screen should return to the page you were last on and the faders will return the positions they were in before the console was locked.

## The More Secure Way

This method is called 'The Combination Lock' because you can set the button combination to lock and unlock the console.

### Locking

1. Press and hold the `HOME` button and any combination of buttons on the console for 3-4 seconds. The screen should change to a blank page and all buttons and faders will no longer respond to changes.

### Unlocking

1. Press and hold the `HOME` button and all the other buttons in your "combination" for 3-4 seconds. The screen should return to the page you were last on and the faders will return the positions they were in before the console was locked.
